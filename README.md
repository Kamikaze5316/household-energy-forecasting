# Прогнозирование энергопотребления домохозяйства

Учебный проект по дисциплине **«Большие данные и машинное обучение»**. Проект исследует временной ряд индивидуального энергопотребления домохозяйства и сравнивает несколько алгоритмов машинного обучения для прогноза средней активной мощности на следующий час.

## Возможности проекта

- загрузка и очистка исходных данных UCI Individual Household Electric Power Consumption;
- преобразование минутных измерений в часовой временной ряд;
- исследовательский анализ, визуализация и календарные/лаговые признаки;
- хронологическое разделение на обучающую, валидационную и тестовую выборки;
- сравнение базовых прогнозов с Ridge, Random Forest, HistGradientBoosting и XGBoost;
- оценка по MAE, RMSE, MAPE, WAPE и R²;
- рекурсивный прогноз на 1–72 часа в Streamlit;
- выгрузка прогнозов и результатов в CSV.

## Структура репозитория

```text
household-energy-forecasting/
├── app.py                              # Streamlit-интерфейс
├── install_model_dependencies.py      # Установка версий библиотек из metadata.json
├── requirements.txt                    # Зависимости приложения
├── run_windows.bat                     # Запуск в Windows
├── notebooks/
│   └── household_energy_forecasting.ipynb  # Полный исследовательский ноутбук
└── artifacts/
    └── README.md                       # Инструкция по добавлению обученной модели
```

Сгенерированные файлы модели и локальные данные намеренно не включены в исходный репозиторий: они создаются при выполнении ноутбука и игнорируются Git.

## Запуск исследовательского проекта

1. Откройте `notebooks/household_energy_forecasting.ipynb` в [Google Colab](https://colab.research.google.com/).
2. Выполните все ячейки сверху вниз.
3. В последней секции ноутбука будет создан архив `streamlit_artifacts.zip`. Скачайте его.
4. Распакуйте каталог `artifacts/` из архива в корень репозитория, чтобы получилась структура `artifacts/best_model.joblib`, `artifacts/metadata.json` и остальные файлы результатов.

## Запуск Streamlit локально (Windows)

Требуется установленный Python. После распаковки артефактов запустите `run_windows.bat`. Скрипт создаст виртуальное окружение `.venv`, установит зависимости, при наличии `artifacts/metadata.json` подберёт версии ML-библиотек, использованные при обучении, и запустит приложение.

После запуска откройте [http://localhost:8501](http://localhost:8501).

### Ручной запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python install_model_dependencies.py
streamlit run app.py
```

Если PowerShell запрещает активацию виртуального окружения, можно запустить приложение без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe install_model_dependencies.py
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Публикация приложения в Streamlit Community Cloud

Для запуска приложения в облаке одного исходного кода недостаточно: Streamlit должен иметь доступ к обученной модели и файлам результатов в `artifacts/`.

Перед публикацией приложения:

1. Сгенерируйте свежий `streamlit_artifacts.zip` в Colab и распакуйте его в `artifacts/`.
2. Проверьте размеры файлов. Не добавляйте исходный архив датасета или виртуальное окружение.
3. Если артефакты небольшие и допустимы для публичного доступа, добавьте их в репозиторий принудительно (`git add -f artifacts/`). Помните, что публичные артефакты смогут скачать все.
4. В [Streamlit Community Cloud](https://share.streamlit.io/) создайте приложение, укажите репозиторий, ветку `main` и файл `app.py`.

Если модель или другие файлы слишком велики для обычного GitHub-репозитория, храните их отдельно (например, в Releases или объектном хранилище) и настройте загрузку при старте приложения. Не используйте Git LFS, не проверив ограничения выбранного хостинга.

## Методология и единицы измерения

Исходные данные представлены минутными измерениями. Целевая переменная — средняя активная мощность за час (`Global_active_power`, кВт). Для интервала длительностью один час численное значение средней мощности в кВт соответствует энергии, потреблённой за этот час, в кВт·ч.

Разделение выборок выполняется по времени, без случайного перемешивания. Для многошагового прогноза Streamlit использует рекурсивный режим: предсказанное значение становится входным значением для последующих шагов, поэтому ошибка может накапливаться с увеличением горизонта.

## Примечание о совместимости модели

Модель сохраняется с помощью Joblib. Для корректной загрузки рекомендуется использовать те же версии Python и ключевых ML-библиотек, которые применялись при обучении. Ноутбук записывает эти версии в `artifacts/metadata.json`, а `install_model_dependencies.py` использует метаданные для согласования окружения. Загружайте только собственные доверенные файлы `.joblib`.
